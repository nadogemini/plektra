# Totkey

Bàn phím Android cho máy có bàn phím vật lý (Unihertz Titan 2 Elite), dựa trên Plektra (GPL-3.0).

- Tiếng Việt Telex, tiếng Trung pinyin, tiếng Anh
- Alt+SYM: chọn bộ gõ
- Giữ SYM: nói tiếng Việt, nhận dạng offline
- Chạm hai lần rồi vuốt: di chuyển con trỏ

Tải bản mới nhất ở mục Releases (tag `totkey-v*`).

## Build
GitHub Actions workflow `Totkey` áp các bản vá trong `personal/` lên mã Plektra rồi build APK.
Đổi số phiên bản ở biến `TOTKEY_VERSION` trong workflow.
